# SA Overseas Website Design

## Reference Design
The website is based on **bhpimpex.ca** - a professional B2B marine feed ingredients exporter. The design features:
- Clean, professional layout with strong visual hierarchy
- Full-width hero section with compelling background image
- Navigation bar with dropdown menus
- Product showcase sections
- Testimonials and certifications
- Contact information and call-to-action buttons
- Responsive design that works on all devices

## Content Source
Content is extracted from **sa-overseas.co.in** featuring:
- Company tagline: "Global Connections. Reliable Solutions."
- 5 premium products: Fish Meal, Fish Oil, Shrimp Meal, Poultry Meal, Dry Fish
- Focus on Bangladesh as primary export market
- Emphasis on quality, reliability, and global shipping
- Contact details and quote request functionality

## Chosen Design Approach: Professional Marine Export

### Design Movement
**Modern Professional B2B** - Clean, trustworthy, and authoritative design that reflects the marine/aquaculture industry.

### Core Principles
1. **Trust Through Clarity** - Clear information hierarchy, professional typography, and structured layouts build confidence
2. **Industry-Specific Visual Language** - Marine/ocean imagery, blue color palette reflecting the product category
3. **Action-Oriented** - Clear CTAs for quote requests and contact, guiding visitors toward conversion
4. **Responsive Excellence** - Mobile-first design ensuring accessibility across all devices

### Color Philosophy
- **Primary Blue** (`#0066CC` / `oklch(0.5 0.15 260)`) - Professional, trustworthy, maritime
- **Ocean Teal** (`#00A8A8` / `oklch(0.55 0.15 200)`) - Secondary accent, natural/organic
- **Deep Navy** (`#1A3A52` / `oklch(0.25 0.08 260)`) - Text and strong elements
- **Light Gray** (`#F5F7FA` / `oklch(0.97 0.01 260)`) - Backgrounds and cards
- **White** (`#FFFFFF`) - Clean, professional spaces

### Layout Paradigm
- **Hero-First Structure** - Compelling hero with background image and overlay
- **Card-Based Product Showcase** - Grid layout for products with hover effects
- **Asymmetric Sections** - Alternating image/text layouts to maintain visual interest
- **Sticky Navigation** - Professional header that stays visible during scroll
- **Full-Width Sections** - Maximizes visual impact while maintaining readability

### Signature Elements
1. **Marine Hero Background** - Full-width image with gradient overlay and centered text
2. **Product Cards** - Clean cards with images, titles, descriptions, and "Learn More" buttons
3. **Feature Icons** - Simple, professional icons for key benefits (quality, shipping, support)
4. **Gradient Accents** - Subtle blue gradients on buttons and hover states

### Interaction Philosophy
- **Smooth Hover Effects** - Buttons scale slightly, cards lift with subtle shadows
- **Clear Focus States** - Keyboard navigation fully supported
- **Responsive Transitions** - All interactions under 300ms for snappy feel
- **Mobile-First Interactions** - Touch-friendly buttons and spacing

### Animation
- Button hover: `scale(1.02)` with `200ms ease-out`
- Card hover: `translateY(-4px)` with subtle shadow increase
- Page transitions: Fade in with `300ms ease-out`
- Scroll animations: Fade in elements as they enter viewport
- Respect `prefers-reduced-motion` for accessibility

### Typography System
- **Display Font**: System fonts with bold weight (700) for headings
- **Body Font**: System fonts with regular weight (400) for body text
- **Hierarchy**:
  - H1: 48px / 56px (desktop/mobile), bold, brand blue
  - H2: 36px / 32px, bold, navy
  - H3: 24px / 20px, semibold, navy
  - Body: 16px / 14px, regular, dark gray
  - Small: 14px / 12px, regular, medium gray

### Brand Essence
**One-liner**: Premium marine feed ingredients exporter delivering global quality with local expertise.

**Personality**: Professional, Reliable, Global

**Brand Voice**: 
- Headlines: Direct, benefit-focused ("Premium Marine Feed Ingredients For Global Markets")
- CTAs: Action-oriented ("Request a Quote", "Explore Products")
- Microcopy: Clear and specific (avoid generic phrases)

### Wordmark & Logo
- **Logo Concept**: Stylized fish or wave symbol (simple, bold, recognizable)
- **Color**: Primary blue (#0066CC)
- **Style**: Modern, geometric, professional
- **Usage**: Header and favicon

### Signature Brand Color
**Ocean Blue** - `#0066CC` (oklch(0.5 0.15 260))
This unmistakable blue represents trust, maritime heritage, and global reach.

## Style Decisions
- Mobile-first responsive design with breakpoints at 640px, 1024px
- Consistent spacing scale: 4px, 8px, 12px, 16px, 24px, 32px, 48px
- Border radius: 8px for cards, 4px for smaller elements
- Shadows: Subtle elevation shadows for depth
- Images: High-quality marine/product imagery with proper contrast
